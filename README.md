# wordpress-branching-story-engine

A PHP/JavaScript engine for interactive branching narratives in WordPress,
with a formal JSON schema (`stp-game-package-1.2`) and a full test suite.

## Status

- 608 Node assertions + PHP test suites — all passing
- 18 project rules, mutation testing, handoff documents
- Self-contained: no CDN, no external dependencies at runtime

## Why this repo is public

I am a software developer working on educational WordPress plugins.
This repo documents the engineering approach and will host
the open-source portions of the engine.
Tests and production code remain in the private repository.
